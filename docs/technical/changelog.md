## [2.0.0] - 2024-12-19

### ✨ Agregado
- **🏗️ Script mejorado** con generación de diccionario de datos completo
- **📊 Diccionario Excel** con múltiples hojas y estadísticas
- **🔗 Diccionario JSON** estructurado para integraciones
- **💬 Comentarios SQL** automáticos con `MS_Description`
- **📁 Estructura organizativa** con carpetas categorizadas
- **📚 Documentación completa** para el equipo
- **🔍 Extracción mejorada** de nombres reales de tablas
- **🏷️ Categorización** por áreas de negocio
- **📋 Descripciones detalladas** de campos y tablas

### 🔧 Mejorado
- **⚡ Performance** optimizada para documentos grandes
- **🎯 Precisión** mejorada en mapeo de tipos de datos
- **🔍 Patrones de extracción** más robustos
- **📝 Logging** detallado para debugging
- **🛡️ Manejo de errores** más robusto

### 🔄 Cambiado
- **📁 Estructura de archivos** reorganizada en carpetas temáticas
- **📝 Nomenclatura** estándar para tablas y columnas
- **🗂️ Separación** entre documentación técnica y de usuario
- **🔧 Configuración** centralizada en variables

### 🛠️ Corregido
- **🐛 Error** en extracción de contexto de tablas
- **🔤 Problema** con caracteres especiales en nombres
- **💾 Issue** de memoria en documentos grandes
- **📊 Bug** en generación de estadísticas
